# Deploying and changing this project

This file used to hold everything — 3,800+ lines by 2026-08-07, grown as an
append-only journal. Split that day into `docs/`, by category, so a
question doesn't require reading the whole history first.

**Start here: [`docs/00-index.md`](docs/00-index.md)** — the index, the
current status, and a table of every file with a one-line description of
what's in it.

Quick links for the two most common needs:

- Standing this up for the first time, or the "change X, also check Y"
  playbook → [`docs/10-deploy-guide.md`](docs/10-deploy-guide.md)
- Why a given data source was chosen (or rejected) and its licensing →
  [`docs/20-data-sources-and-licensing.md`](docs/20-data-sources-and-licensing.md)

`README.md` explains what the commands do. `docs/` explains what to run, in
what order, and what breaks if you don't — and now, which specific file to
open for which question.
